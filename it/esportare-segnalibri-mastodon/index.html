Segnalibri di Mastodon

Esporta i tuoi segnalibri di Mastodon

Scarica ogni post che hai salvato nei segnalibri di Mastodon come un file di preferiti che il tuo browser, Raindrop.io, Pinboard o qualsiasi servizio di segnalibri può importare. Hai salvato un post per l’articolo che condivideva? Scartalo e tieni l’articolo. Accedi con Mastodon per iniziare.

  1. Leggi i tuoi segnalibri

    Tutti i segnalibri del tuo account Mastodon, letti dal tuo server.

  2. Scegli cosa tenere

    I post stessi, i link che condividevano (“scartati”), o solo i segnalibri che condividevano un link.

  3. Importa il file

    Un normale file di preferiti: apri il gestore dei preferiti del browser o il tuo servizio di segnalibri e importalo.

Domande

Mastodon non esporta già i segnalibri?

La sua esportazione dei dati elenca i segnalibri come una tabella di indirizzi di post, che browser e servizi di segnalibri non importano. Questo file sì, con titoli, testo e hashtag.

Cosa vuol dire “scartare”?

La maggior parte dei post salvati è stata condivisa per un link: un articolo, un video, un progetto. Scartare salva quel link invece del post che ne parla, con il testo del post come descrizione.

I miei segnalibri vengono caricati da qualche parte?

No. Vengono letti dal tuo server Mastodon e il file viene creato nel tuo browser. Niente viene mandato a Mawkingbird.

Le date sono giuste?

Ogni segnalibro porta la data in cui è stato scritto il post. Mastodon non registra quando l’hai salvato.
