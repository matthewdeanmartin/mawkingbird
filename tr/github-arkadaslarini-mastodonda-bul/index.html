GitHub arkadaşlarını Mastodon'da bul

Birçok geliştirici GitHub'da Mastodon hesabını belirtir. Mawkingbird GitHub'da takip ettiklerini ve yıldızladığın depoların sahiplerini kontrol edip Mastodon'da takip etmeni sağlar.

  1. Mastodon ile oturum aç

    Takip işlemi kendi Mastodon hesabında yapılacağı için önce bu gerekir.

  2. GitHub'ı bağla

    GitHub kişisel erişim belirtecini yapıştır; sayfa nasıl oluşturacağını gösterir. GitHub tarayıcı uygulamalarına başka giriş yolu sunmaz ve belirteç bu tarayıcıda kalır.

  3. Bul ve takip et

    Önce Mastodon profil bağlantıları, sonra sınırlı kullanıcı adı araması. Her eşleşme kanıtını gösterir; kimi takip edeceğini sen seçersin.
