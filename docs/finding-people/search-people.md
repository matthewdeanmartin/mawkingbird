# Search for a particular person

Search by account when you already know a name, username, handle, or profile address.

## Search for the account

1. Choose **Search** in the main navigation.
2. Choose the network where you expect the account to be: **Mastodon** or **Bluesky**.
3. Choose **Accounts**.
4. Enter the person's name or handle.
5. Choose **Search**.
6. Open a likely result and check the profile before following.

A full handle is usually more reliable than a display name. Examples are `@name@server.example` for Mastodon and `name.bsky.social` for Bluesky.

You can also paste a Mastodon profile address into search.

## Confirm that it is the right person

Display names are not unique. Check several clues:

- the full handle;
- profile biography;
- profile links;
- recent posts;
- profile picture;
- accounts the profile features or interacts with.

Do not rely on a familiar name and picture alone.

## If the account is missing

- Check spelling and punctuation in the handle.
- Make sure the correct network is selected.
- For Mastodon, include both the username and server in the full handle.
- Paste the complete profile address if you have it.
- Try again later if the account's server is unavailable.

A Mastodon server does not automatically know every account on the wider network. A full handle gives it the best chance to find the remote account.
