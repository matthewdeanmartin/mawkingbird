# Mawkingbird Help

Mawkingbird lets you read, follow, and post across social networks from one place.

You do not need to understand how social networks are built to use it. You can start by looking around, sign in with an account you already have, or learn one task at a time.

## New to Mawkingbird?

Start with [Welcome to Mawkingbird](start/welcome.md). It explains what you are looking at without assuming you have used social media before.

If you want to get moving immediately, follow [Your first ten minutes](start/first-ten-minutes.md).
