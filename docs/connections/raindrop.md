# Save bookmarks to Raindrop.io

Connect Raindrop.io when you want a second place to save bookmarks. For a post containing a link, Mawkingbird can save either the post or its first outside link.

## Connect

1. Open Raindrop.io's **App Management Console**.
2. Create or open an app.
3. Copy the **Test token** from the app's settings.
4. In Mawkingbird, open **Settings → Connections → Raindrop.io**.
5. Paste the token and choose **Save connection**.

The token grants access to your Raindrop.io account. Use it only on a device and browser profile you trust.

## Save a bookmark

Use the bookmark action on a post. When Mawkingbird offers a destination, choose Raindrop.io.

If the post's main value is an article or site it links to, choose the option to save the first external link. Mawkingbird skips hashtags and links that merely return to the social server.

## Disconnect

Return to the Raindrop.io connection page and choose **Disconnect**. To invalidate the old token everywhere, replace or revoke it in Raindrop.io.
