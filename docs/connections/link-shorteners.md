# Connect a link shortener

A link shortener turns a long address into a compact one while you write. Mawkingbird supports the services listed on **Settings → Connections → Link shortener**.

Short links hide their destination at a glance and may stop working if the shortening service closes or the link is deleted. Use the original address when clarity and permanence matter more than length.

## Connect a service

1. Open **Settings → Connections → Link shortener**.
2. Choose a service such as Dub, Short.io, T.LY, or an account-free choice shown there.
3. If the service uses accounts, follow its settings link and create the key named on the page.
4. If requested, enter the short domain from your account.
5. Paste the key and choose **Save and test connection**. For an account-free service, choose **Use _service name_** instead.

Mawkingbird tests the choice before saving it. If you connect more than one service, choose **Make active** beside the one you want to use.

## Shorten a link

While writing a post, use the shorten-link action beside a web address. Review the result before publishing. The connection page keeps a list of links you made and provides controls for deleting old ones when the service supports it.

## Disconnect

Choose **Disconnect** beside the service. Revoke the key on the service's own account page if you no longer need it.
