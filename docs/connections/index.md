# Connections

A connection lets Mawkingbird work with an account or service you already use. You do not need to connect everything. Add only the services that solve a problem for you.

Open **Settings → Connections**. Each card says whether it is connected and what it adds.

## Choose by what you want to do

- Read and respond on another social network: [Mastodon](mastodon.md) or [Bluesky](bluesky.md).
- Keep reading public Twitter accounts: [Twitter](twitter.md).
- Save bookmarks elsewhere: [Raindrop.io](raindrop.md).
- Find people you know from GitHub or read GitHub notices: [GitHub](github.md).
- Browse files kept for Mawkingbird: [Dropbox](dropbox.md).
- Get writing and search assistance: [OpenRouter](openrouter.md).
- Shorten links while writing: [Link shorteners](link-shorteners.md).
- Publish longer writing: [Blogs](blogs.md).
- Publish a paste: [GitHub Gist](github-gist.md).
- Help Mawkingbird reach a public feed or service your browser cannot reach directly: [Mawkingbird proxy](cors-proxy.md).

RSS feeds have their own area under **Settings → RSS feeds**. Subscribing to a feed is not a connection.

## Before connecting

Read the connection card before entering a key or approving access. It tells you what the connection can do and whether it belongs to one signed-in account, all accounts in this browser, or only the current tab.

Use a device and browser profile you trust. If a service lets you limit permissions, grant only the permissions named on Mawkingbird's connection page.

## Disconnect

Return to **Settings → Connections**, open the service, and choose **Disconnect**, **Unlink**, or **Sign out**. The wording varies by service.

Disconnecting stops Mawkingbird from using the saved connection. For extra certainty, you can also revoke Mawkingbird's password, key, or permission from the service itself.

If a connection fails before or after setup, use [Connection Doctor](connection-doctor.md).
