# Connect GitHub Gist for pastes

A gist is a page for text or code that is too large or awkward for a social post. This connection adds **GitHub Gist** wherever Mawkingbird lets you publish a paste.

Gists do not expire. They belong to your GitHub account, and you can edit or delete them later.

## Connect

1. In GitHub, create a classic personal access token with only the `gist` permission.
2. Open **Settings → Connections → GitHub Gist**.
3. Paste the token into **Personal access token (classic, gist scope)**.
4. Choose **Connect**.

This token can create, edit, and delete your gists. Use a trusted device and revoke the token in GitHub when you are finished with it.

## Publish a gist

Choose **GitHub Gist** as the paste destination. Gists you create appear in **Drafts** and **Write** with other pastes.

Before publishing sensitive text, check whether the gist will be public or secret. A secret gist is unlisted, not protected by a password; anyone with its address can read it.

## Disconnect

Choose **Disconnect** on the connection page. Existing gists stay in your GitHub account.

The read-only [GitHub connection](github.md) is separate.
