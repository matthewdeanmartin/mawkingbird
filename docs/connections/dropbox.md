# Connect Dropbox

The Dropbox connection gives Mawkingbird an app-specific folder in your Dropbox. Mawkingbird can browse files in that folder; it does not receive access to the rest of your Dropbox.

## Connect

1. Open **Settings → Connections → Dropbox**.
2. Choose **Connect Dropbox**.
3. Approve the request on Dropbox's page.
4. Return to Mawkingbird.

The connection page now shows that Dropbox is connected.

## Check the folder

Choose **List files and folders**. Mawkingbird opens a list of files and folders it can see. If the list is empty, add a file to Mawkingbird's app folder in Dropbox and try again.

## Disconnect

Choose **Disconnect** on the connection page. You can also remove Mawkingbird from Dropbox's connected-app settings.

Disconnecting does not delete the files in Dropbox. Manage or delete those files from Dropbox when needed.
