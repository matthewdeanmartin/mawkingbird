# RSS reader

Use **Apps → RSS** to read websites and blogs as they publish new articles. A feed is the list of updates a site makes available to readers.

Start with a site you already read. [Find its RSS feed and add it to Mawkingbird](../finding-people/rss-discovery.md), then open **Read** to see its articles. Use **Later** to return to articles you’ve saved.

You can also [read a public Mastodon or Bluesky account as RSS](../reading/mastodon-bluesky-rss.md).
