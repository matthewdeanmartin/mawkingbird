# Write useful media descriptions

A media description tells someone what an attachment contains when they cannot see it. Screen readers use it, and it can also help when an image fails to load.

## Add a description

1. Attach the media to your post.
2. Find the text field beneath its preview.
3. Describe the important content of that attachment.
4. Repeat for every attachment.

Mawkingbird labels the field **Describe for the visually impaired**.

## What to write

Describe the information a reader needs from the media, not every pixel.

Useful descriptions often include:

- the people, objects, or setting that matter;
- visible text that is important to the post;
- the point of a chart or diagram;
- an action, expression, or visual joke that carries meaning.

For example, instead of “a screenshot,” write “Weather forecast showing heavy rain from 2 to 6 p.m.”

Keep the surrounding post in mind. You do not need to repeat details already stated clearly in the post unless they are needed to understand the image.

## Make descriptions required

Mawkingbird normally warns when an attachment has no description. You can make the Post button wait until every attachment is described:

1. Open **More → Settings**.
2. Choose **Writing**.
3. Turn on **Require a description on every attachment before posting**.

This choice is useful if you often forget descriptions while posting quickly.
