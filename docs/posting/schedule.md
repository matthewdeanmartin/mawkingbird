# Schedule a post

Scheduling gives a Fedi server a post now and asks it to publish at a future time. The browser does not need to remain open afterward.

## Schedule it

1. Start a new Fedi post.
2. Choose the clock button.
3. Set **Publish at** to the intended date and time.
4. Review the text, visibility, and time zone shown by your device.
5. Choose **Schedule**.

Choose a time at least ten minutes in the future. A server may publish a time less than about five minutes away immediately instead of scheduling it.

Mawkingbird confirms the scheduled time and lists the post under **More → Drafts → Scheduled**.

## Cancel a scheduled post

1. Open **More → Drafts**.
2. Find the item under **Scheduled**.
3. Choose **Cancel**.
4. Confirm the cancellation.

Cancellation deletes the scheduled item from the server, and it will not publish. Copy any text you want to keep before cancelling.

## Limits

Scheduling is Fedi-only. It is unavailable when the destination includes Bluesky.

A scheduled item must be one new post. Replies, quotes, and threads cannot be scheduled from Mawkingbird. Blog and paste destinations also do not use this scheduling control.

A scheduled post is not an ordinary draft: it will publish automatically unless you cancel it.
