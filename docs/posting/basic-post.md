# Write and publish a basic post

A post is a short message published from one of your connected accounts. Start with text only; polls, media, threads, and scheduling can wait until you need them.

## Before you publish

Make sure you are using the intended account. If you have more than one account saved, the current account appears in the account menu at the top of Mawkingbird.

## Publish from Home

1. Choose **Home**.
2. Choose **Quick post**.
3. Write your message in the text box.
4. Check the destination below the box. For example, it may show Fedi, Bluesky, or both.
5. Check the visibility beside the destination. If you are unsure, stop and learn what the offered choice means before publishing.
6. Choose **Post**.

Mawkingbird may give you a short countdown before sending. Choose **Cancel** if you notice a mistake, or **Publish now** if you do not want to wait.

The post appears in your feed after it is accepted. A slower server may take a moment to show it.

## If you see Write instead of Quick post

Your writing preference may be set to a more deliberate mode.

1. Choose **Write**.
2. Write your message.
3. Save it.
4. Open **More → Drafts**.
5. Review the draft and publish it when ready.

In this mode, saving is not the same as publishing. The draft remains private until you deliberately publish it.

## If the Post button is unavailable

Check the messages around the composer. Common reasons include:

- the message is empty;
- the message is too long for its destination;
- a required image description is missing;
- the selected destination does not support an added poll or other option;
- the account is not signed in or connected;
- the post is scheduled too soon or has incompatible options.

Mawkingbird normally explains the specific problem beside the composer.

## If posting fails

Your text stays in the composer. Read the **Not posted** message, correct the problem it names, and try again. Do not repeatedly press Post while the first attempt is still working.
