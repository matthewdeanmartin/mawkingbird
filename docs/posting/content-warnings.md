# Add a content warning

A content warning places a short label in front of a post. Readers see the label first and choose whether to reveal the body.

Content warnings are useful for subjects readers may want to approach deliberately. They can also act as a subject line for a long post.

## Add one

1. Start a new post.
2. Choose **CW**.
3. Enter a brief, useful label in the new field.
4. Write the full post in the main box.
5. Publish it.

The label should help someone decide whether to open the post. “Medical discussion: needles” is more useful than “warning,” because it says what the warning is about.

Choose **CW** again to remove the warning. Removing it also clears the warning text.

## Sensitive media is separate

If the post includes media that should be hidden initially, also choose the sensitive-media warning button. In Mawkingbird, adding a content warning does not replace the sensitive-media choice.

## Destination differences

Content warnings are a Fedi feature. Bluesky does not receive the content warning from Mawkingbird.

If the destination is **Both**, the Fedi copy receives the warning and the Bluesky copy receives the body without it. Make sure the Bluesky copy is appropriate to publish openly without that warning layer.
