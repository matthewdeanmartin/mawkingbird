# Add a photo or other media

You can attach media to a post from the composer. The kinds and sizes accepted depend on the destination and, for Fedi, the server holding your account.

## Attach media

1. Start a new post.
2. Choose the paperclip button.
3. Select one or more files.
4. Wait for Mawkingbird to show a preview of each accepted attachment.
5. Add a description to each attachment.
6. Write the post and publish it.

You can also paste an image into the writing box or drag files onto the composer.

Use the remove button beside a preview if you selected the wrong file.

## Destination differences

Fedi servers can accept images, animated images, video, and audio, but each server sets its own limits.

Bluesky posting in Mawkingbird accepts images only, with no more than four images per post. If you switch an existing post to Bluesky or Both, Mawkingbird tells you when an attachment will be left out of the Bluesky copy.

When posting to **Both**, supported images go to both destinations. Video or audio may go only to Fedi.

Read the message beside the composer before publishing. It describes what Mawkingbird will leave out rather than silently pretending every destination is identical.

## Media and polls cannot be combined

A post can contain attached media or a poll, but not both. Remove the poll before adding media, or remove all media before adding a poll.

## Sensitive media

Use the warning button to mark attached media as sensitive when readers should choose whether to reveal it. A content warning and a sensitive-media label are separate choices in Mawkingbird.
