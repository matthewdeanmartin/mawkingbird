Method

How the trial worked

Each model received the same writing brief: tell an original 500–750-word story in each language about a generation ship bound for Barnard’s Star whose voyage goes horribly wrong. Each model received the same eight UI message keys and four offline-reader source strings, with identical placeholders.

Two AI peers evaluated each entry under anonymous labels. Each reviewer assigned integer scores from 0 to 5. The four UI criteria carry equal weight, as do the three fiction criteria. A 5 means excellent, 4 a minor issue, 3 a noticeable repair, 2 major issues, 1 mostly unusable and 0 absent. Each total is the mean of the corresponding scores across both reviewers, scaled to 100. Rank uses the unrounded UI total, with identical scores sharing a place.

This small trial covers one story brief and one set of interface strings. There was no human adjudication or testing with readers in either country.
