# Action row parity

Written for: commit `649a34d4a` and later. Status: not run.

Bluesky and Mastodon posts should have the same action row: each count right
after its icon, in the same type.

## Setup

Signed in with **Mastodon M** and a Bluesky connection to **Bluesky A**, so Home
shows both networks.

## Steps

- [ ] 1. Find a Mastodon post and a Bluesky post with boosts and likes, close
      together in Home. Compare their rows side by side.
- [ ] 2. Each count sits immediately after its icon on both: 💬 N · 🔁 N · ⭐ N.
      On Mastodon, Quote (❝) follows the boost count.
- [ ] 3. The counts look identical: same size, weight and colour. No muted grey
      text on Bluesky.
- [ ] 4. Tap the Bluesky like count: a "Favourited by" list opens with Bluesky
      accounts. Tap the repost count: the reposters open.
- [ ] 5. Same checks at phone width (about 400 px) and in dark mode.
- [ ] 6. Signed out (anonymous), open a public Mastodon post: counts show and
      are not dressed as buttons where they cannot act.
