# Latvian starter kits

Run on a preview or deployment containing this change. DOM rendering and the
offline importer were tested; the browser flows below remain manual checks.

1. Open `/lv/mastodon-kopienas` signed out at desktop and phone widths. Check the
   Latvian headings, category navigation and links to both new kits. Confirm the
   English communities hub also lists the two editions and offers Latvian.
2. Open `/lv/tehnologijas-un-atvertais-kods-mastodon` and
   `/lv/maksla-un-kultura-mastodon`. Each should show seven profiles and three
   tags. Confirm the first page explains quiet local tags/English FOSS content,
   and the second explains the quiet Grāmatas tag. Inspect Latvian diacritics,
   mobile wrapping, account links and keyboard focus.
3. Preview a selection signed out. Check Latvian buttons/status text, shuffle
   and empty states. Shared tags may show English or unrelated posts; activity
   must reflect the live sample, not promise a busy Latvian timeline.
4. Sign in with Mastodon from the selection. Confirm return to the same page and
   step with selections retained. With a test account, follow a selected profile
   and tag, then check that already-followed/progress states are intelligible.
5. Create a list with the Latvian topic title. Check the exclusive-list option,
   completion message and list link. Use a test account for these mutations.
6. Return to ordinary app pages and confirm the pinned public-page language did
   not silently overwrite an explicit interface-language preference. Check a
   previous English/German kit to confirm its membership and date are unchanged.

No new endpoint or transport was introduced. When checking Native, exercise the
same public preview and follow/list paths through its existing typed transports.
