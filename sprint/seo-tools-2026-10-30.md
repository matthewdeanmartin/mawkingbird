# SEO tool pages: two sprints, 2026-10-30

Status: both sprints implemented and verified locally, uncommitted.

Four more focused mini-apps (public, prerendered entry pages for one task; see
`ui/docs/seo.md`, "Focused mini-apps"), each reusing a feature that already
ships, after first replacing the hand-wired tool lists with one registry.

## Owner decisions (2026-10-30)

- Bluesky ⇄ Mastodon is one screen at two URLs: `/bluesky-to-mastodon` and
  `/mastodon-to-bluesky`. The URL sets the direction.
- "Turn off boosts" is modelled on the single-purpose "turn off retweets" sites
  for Twitter.
- "Find your friends' feeds" (profile links → feeds → OPML) stays **Plus-only**.
  The landing page explains it and signs in; non-supporters then see the
  existing Plus offer.
- "Find your contacts on Mastodon" signs in with Mastodon first, like the other
  tools, although the feature also works anonymously in Settings.
- Sprint 1 starts by driving every tool list from one registry, so a page cannot
  be half-registered.

## Results

### Sprint 1 (2026-10-30)

- S1-1: `ui/src/app/focused-tools.json` (typed by `focused-tools.ts`) now drives
  routes, the trimmed nav, the `?next=` allowlist, prerendering, the sitemap and
  its dates, the no-JS links, the features page and the route spec. Tool URLs
  left `public/sitemap.xml`; `prepare-seo-index.mjs` appends them and
  `check-seo-build.mjs` compares the sitemap exactly. The five description
  constants left `seo.ts`. The registry is in the initial bundle because the
  eager routes need titles and descriptions.
- S1-2: `bridge-friends-import` holds the bridge finder; Settings renders it
  unchanged. Inputs `fixedSource` and `connectInline` serve the tool pages.
- S1-3: one `FriendBridge` page; the direction comes from the route path, so
  the public page, the signed-in twin and the prerender agree.
- S1-4: `/turn-off-boosts-mastodon` hosts the existing `reblogs-off` and
  `reblogs-on` bulk actions, their count-first dialog and the progress panel.
- Gates: targeted specs; `make test` exit 0 (8,572 present, 0 missing);
  `make test-seo` (29 routes) and `npm run test:seo:browser` passed.

### Sprint 2 (2026-10-30)

- S2-1: `contact-friends-import` holds the contacts finder; Settings renders it
  unchanged and keeps `id="contacts"` for /find-friends.
- S2-2: `/find-contacts-on-mastodon`; next steps appear after the first search.
- S2-3: `/mastodon-friends-rss-feeds` opens the existing friend-feeds dialog,

- Gates: targeted specs (16 files); ESLint, Prettier, `check:i18n`,
