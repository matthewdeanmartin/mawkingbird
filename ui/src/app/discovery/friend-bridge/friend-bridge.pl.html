Pytania

Czy obserwuje ludzi bez pytania?

Nie. Osoby, które same podały drugą nazwę, są dla Ciebie zaznaczone; zgadywanie z wyszukiwania po nazwie już nie. Nikt nie zostanie zaobserwowany, zanim klikniesz „Obserwuj”.

Dlaczego niektórych osób brakuje?

Dopasowywane są tylko osoby, które podają swoją drugą nazwę, albo te, które znajdzie wyszukiwanie po nazwie. Ktoś z popularnym imieniem i pustym bio może się nie pojawić.

A w drugą stronę?

Też działa: @if (copy.source === 'bluesky') { znajdź na Bluesky osoby, które obserwujesz na Mastodonie. } @else { znajdź na Mastodonie osoby, które obserwujesz na Bluesky. }

Gdzie są zapisane moje logowania?

W tej przeglądarce. Mawkingbird rozmawia bezpośrednio z Twoim serwerem Mastodona i z Bluesky; nie ma po drodze żadnego serwera Mawkingbird, który przechowuje Twoje konta.
