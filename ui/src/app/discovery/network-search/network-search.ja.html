Mastodon のアカウントは必要ですか？

不要です。アカウントがなくても、人とハッシュタグ、ハッシュタグによる投稿を検索できます。Mastodon サーバーは匿名での全文検索を許していないため、投稿の本文を検索するにはログインしてください。ログイン後はこのページに戻ります。

サーバーの検索とどう違いますか？

検索するのは同じサーバーですが、ここでは検索欄 1 つだけでなく、フィルター、並べ替え、保存した検索、何を検索したかの説明が使えます。

Bluesky も検索できますか？
