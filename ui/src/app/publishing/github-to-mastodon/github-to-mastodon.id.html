GitHub ke Mastodon

Temukan teman GitHub di Mastodon

Banyak pengembang mencantumkan akun Mastodon di GitHub. Mawkingbird memeriksa orang yang kamu ikuti di GitHub dan pemilik repositori yang kamu beri bintang, lalu membantumu mengikuti mereka di Mastodon.

  1. Masuk dengan Mastodon

    Mengikuti dilakukan lewat akun Mastodon-mu sendiri, jadi masuk dulu.

  2. Hubungkan GitHub

    Tempel token akses pribadi GitHub. Halaman ini menjelaskan cara membuatnya. GitHub tidak mengizinkan aplikasi browser masuk dengan cara lain. Token tetap di browser ini.

  3. Temukan dan ikuti

    Tautan profil Mastodon diperiksa lebih dulu, lalu pencarian nama pengguna yang terbatas. Setiap kecocokan disertai petunjuknya. Kamu memilih siapa yang diikuti.

Pertanyaan

Ke mana token GitHub-ku dikirim?

Token disimpan di browser ini dan hanya dikirim ke api.github.com, tidak pernah ke Mawkingbird. Cabut token di GitHub kapan saja.

Apakah orang akan diikuti secara otomatis?

Tidak. Setiap tindakan mengikuti memerlukan tombol yang kamu tekan sendiri, di samping petunjuk kecocokan.
