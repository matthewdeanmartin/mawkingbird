De GitHub à Mastodon

Retrouver tes amis GitHub sur Mastodon

Beaucoup de développeuses et de développeurs indiquent leur compte Mastodon sur GitHub. Mawkingbird vérifie les personnes que tu suis sur GitHub et les propriétaires des dépôts que tu as mis en favori, et te permet de les suivre sur Mastodon.

  1. Te connecter avec Mastodon

  2. Relier GitHub

  3. Trouver et suivre

Questions

Où va mon jeton GitHub ?

Il est enregistré dans ce navigateur et envoyé uniquement à api.github.com, jamais à Mawkingbird. Révoque-le sur GitHub quand tu veux.

Est-ce que ça suit des gens automatiquement ?

Non. Chaque abonnement est un bouton sur lequel tu appuies, à côté des indices.
