GitHub से Mastodon

GitHub के दोस्तों को Mastodon पर खोजें

कई डेवलपर GitHub पर अपना Mastodon अकाउंट बताते हैं। Mawkingbird आपके फ़ॉलो किए लोगों और स्टार किए रिपॉज़िटरी के मालिकों को जाँचता है, ताकि आप उन्हें Mastodon पर फ़ॉलो कर सकें।

सवाल

मेरा GitHub टोकन कहाँ जाता है?

यह इसी ब्राउज़र में रखा जाता है और केवल api.github.com को भेजा जाता है, Mawkingbird को कभी नहीं। GitHub पर कभी भी इसे रद्द कर सकते हैं।

क्या यह किसी को अपने-आप फ़ॉलो करता है?

नहीं। हर फ़ॉलो के लिए मेल के सबूत के पास दिया बटन आपको दबाना होता है।
