Da GitHub a Mastodon

Ritrova i tuoi amici di GitHub su Mastodon

Molte sviluppatrici e molti sviluppatori indicano il loro account Mastodon su GitHub. Mawkingbird controlla chi segui su GitHub e i proprietari dei repository a cui hai messo una stella, e ti permette di seguirli su Mastodon.

  1. Accedi con Mastodon

  2. Collega GitHub

Domande

Dove va il mio token di GitHub?

Viene salvato in questo browser e mandato solo a api.github.com, mai a Mawkingbird. Revocalo su GitHub quando vuoi.

Segue le persone in automatico?

No. Ogni follow è un pulsante che premi tu, accanto agli indizi del risultato.
