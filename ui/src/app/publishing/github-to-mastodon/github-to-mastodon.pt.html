Do GitHub para o Mastodon

Encontre seus amigos do GitHub no Mastodon

Muita gente que programa coloca a conta do Mastodon no GitHub. O Mawkingbird confere quem você segue no GitHub e os donos dos repositórios que você marcou com estrela, e deixa você seguir essas pessoas no Mastodon.

  1. Entre com o Mastodon

  2. Conecte o GitHub

  3. Encontre e siga

Perguntas

Para onde vai meu token do GitHub?

Ele fica salvo neste navegador e só é enviado para api.github.com, nunca para o Mawkingbird. Revogue no GitHub quando quiser.

Ele segue pessoas automaticamente?

Não. Cada seguida é um botão que você aperta, ao lado das pistas do resultado.
