De GitHub a Mastodon

Encuentra a tus amigos de GitHub en Mastodon

Muchas personas que programan ponen su cuenta de Mastodon en GitHub. Mawkingbird revisa a quienes sigues en GitHub y a los dueños de los repositorios que marcaste con estrella, y te deja seguirlos en Mastodon.

Preguntas

¿Adónde va mi token de GitHub?

Se guarda en este navegador y solo se envía a api.github.com, nunca a Mawkingbird. Revócalo en GitHub cuando quieras.

¿Sigue a gente automáticamente?

No. Cada seguimiento es un botón que pulsas tú, junto a las pistas de la coincidencia.
