Pertanyaan

Apakah Mastodon bisa menjadwalkan postingan?

Bisa. Setiap server Mastodon dapat menyimpan postingan untuk diterbitkan nanti, tetapi situs Mastodon standar tidak punya tombol untuk itu. Halaman ini memakai penjadwalan bawaan tersebut. Postingan disimpan di servermu, bukan di Mawkingbird.

Apakah halaman ini harus tetap terbuka?

Tidak. Setelah dijadwalkan, postingan berada di server Mastodon-mu. Server menerbitkannya pada waktu yang dipilih, meskipun komputermu mati.

Apakah ada batasnya?

Mastodon mengizinkan 300 postingan terjadwal sekaligus dan 25 pada satu hari. Masing-masing harus setidaknya lima menit lagi. Penjadwal memeriksa batas ini sebelum mengirim apa pun.

Bisakah aku berubah pikiran?

Bisa. Postingan terjadwal ditampilkan di bawah penjadwal dan bisa dibatalkan sebelum terbit.

Apakah ini bisa untuk Bluesky?

Tidak di sini. Bluesky tidak punya penjadwalan bawaan, jadi halaman ini hanya untuk Mastodon.
