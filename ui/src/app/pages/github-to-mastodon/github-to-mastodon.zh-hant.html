從 GitHub 到 Mastodon

在 Mastodon 找到您 GitHub 上的朋友

很多開發者會在 GitHub 上寫出自己的 Mastodon 帳號。Mawkingbird 會檢查您在 GitHub 跟隨的人，以及您加星號的儲存庫擁有者，讓您在 Mastodon 跟隨他們。

  1. 用 Mastodon 登入

  2. 連結 GitHub

常見問題

我的 GitHub 權杖會送到哪裡？

它存在這個瀏覽器裡，只會送到 api.github.com，絕不會送到 Mawkingbird。您隨時可以在 GitHub 撤銷它。

會自動幫我跟隨別人嗎？

不會。每一次跟隨都是您在線索旁邊自己按下的按鈕。
