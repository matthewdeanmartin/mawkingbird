Из GitHub в Mastodon

Найди знакомых из GitHub в Mastodon

Многие разработчики указывают Mastodon в профиле GitHub. Mawkingbird проверяет твои подписки в GitHub и владельцев репозиториев, отмеченных звездой, чтобы можно было подписаться на них в Mastodon.

Вопросы

Куда отправляется мой токен GitHub?

Он хранится в этом браузере и отправляется только на api.github.com, но не в Mawkingbird. Его можно в любой момент отозвать в GitHub.

Подписки оформляются автоматически?

Нет. Для каждой подписки нужно нажать кнопку рядом с пояснением совпадения.
