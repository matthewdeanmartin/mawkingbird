GitHub to Mastodon

Find your GitHub friends on Mastodon

Many developers list their Mastodon account on GitHub. Mawkingbird checks the people you follow on GitHub, and the owners of repositories you starred, and lets you follow them on Mastodon.

  1. Sign in with Mastodon

    Following happens on your own Mastodon account, so that comes first.

  2. Connect GitHub

    Paste a GitHub personal access token; the page shows how to make one. GitHub does not let browser apps sign in any other way, and the token stays in this browser.

  3. Find and follow

    Profile links to Mastodon come first, then a limited username search. Each match shows its evidence, and you choose who to follow.

Questions

Where does my GitHub token go?

It is stored in this browser and sent only to api.github.com, never to Mawkingbird. Revoke it on GitHub whenever you like.

Does it follow anyone automatically?

No. Every follow is a button you press, next to the evidence for the match.
