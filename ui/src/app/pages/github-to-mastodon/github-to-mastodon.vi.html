GitHub sang Mastodon

Tìm bạn bè GitHub trên Mastodon

Nhiều lập trình viên ghi tài khoản Mastodon trên GitHub. Mawkingbird kiểm tra người bạn theo dõi trên GitHub và chủ kho mã bạn gắn sao để bạn theo dõi họ trên Mastodon.

  3. Tìm và theo dõi

    Ưu tiên liên kết hồ sơ đến Mastodon, rồi tìm tên người dùng với giới hạn. Mỗi kết quả có bằng chứng để bạn chọn người theo dõi.

Câu hỏi

Mã GitHub của tôi đi đâu?

Mã được giữ trong trình duyệt và chỉ gửi tới api.github.com, không gửi tới Mawkingbird. Bạn có thể thu hồi trên GitHub bất cứ lúc nào.

Có tự động theo dõi ai không?

Không. Mỗi lần theo dõi đều do bạn nhấn nút bên cạnh bằng chứng của kết quả.
