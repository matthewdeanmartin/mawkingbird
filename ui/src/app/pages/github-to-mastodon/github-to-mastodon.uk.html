З GitHub у Mastodon

Знайдіть друзів із GitHub у Mastodon

Багато розробниць і розробників указують у GitHub свій обліковий запис Mastodon. Mawkingbird перевіряє людей, за якими ви стежите в GitHub, і власників репозиторіїв, які ви позначили зірочкою, і дає змогу підписатися на них у Mastodon.

Запитання

Куди потрапляє мій токен GitHub?

Він зберігається в цьому браузері й надсилається лише на api.github.com, ніколи в Mawkingbird. Відкличте його в GitHub будь-коли.

Він підписується на людей автоматично?

Ні. Кожна підписка — це кнопка, яку ви натискаєте поруч із доказами збігу.
