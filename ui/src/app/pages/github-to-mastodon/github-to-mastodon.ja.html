GitHub から Mastodon へ

GitHub の知り合いを Mastodon で探す

GitHub のプロフィールに Mastodon のアカウントを載せている開発者はたくさんいます。GitHub でフォローしている人や、スターを付けたリポジトリの持ち主を調べて、Mastodon でフォローできるようにします。

  1. Mastodon でログイン

    フォローはあなた自身の Mastodon アカウントで行うため、まずログインします。

  2. GitHub を連携

    GitHub の個人用アクセストークンを貼り付けます。作り方はページで案内します。GitHub はブラウザーアプリにほかのログイン方法を用意しておらず、トークンはこのブラウザーの中に保存されます。

  3. 見つけてフォロー

    まずプロフィールにある Mastodon へのリンクを、次に件数を絞ったユーザー名検索を使います。候補にはそれぞれ根拠が表示され、誰をフォローするかはあなたが決めます。

よくある質問

GitHub のトークンはどこに送られますか？

このブラウザーに保存され、api.github.com にだけ送られます。Mawkingbird に送られることはありません。GitHub でいつでも無効にできます。

自動でフォローされますか？

いいえ。フォローはすべて、候補の根拠の横にあるボタンをあなたが押して行います。
