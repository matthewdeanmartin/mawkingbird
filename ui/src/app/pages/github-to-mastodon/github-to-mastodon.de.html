Von GitHub zu Mastodon

Deine GitHub-Freunde auf Mastodon finden

Viele Entwicklerinnen und Entwickler nennen ihr Mastodon-Konto auf GitHub. Mawkingbird prüft die Leute, denen du auf GitHub folgst, und die Besitzer der Repositories, die du mit einem Stern markiert hast, und lässt dich ihnen auf Mastodon folgen.

Fragen

Wohin geht mein GitHub-Token?

Es wird in diesem Browser gespeichert und nur an api.github.com geschickt, nie an Mawkingbird. Widerrufe es auf GitHub, wann immer du willst.

Folgt es automatisch jemandem?

Nein. Jedes Folgen ist ein Knopf, den du drückst, neben den Belegen für den Treffer.
