Från GitHub till Mastodon

Hitta dina GitHub-vänner på Mastodon

Många utvecklare anger sitt Mastodon-konto på GitHub. Mawkingbird kontrollerar dem du följer på GitHub och ägarna till arkiv du stjärnmarkerat, så att du kan följa dem på Mastodon.

Frågor

Vart skickas min GitHub-token?

Den sparas i webbläsaren och skickas bara till api.github.com, aldrig till Mawkingbird. Du kan återkalla den på GitHub när du vill.

Följer verktyget någon automatiskt?

Nej. Du trycker själv på en knapp vid underlaget för varje träff.
