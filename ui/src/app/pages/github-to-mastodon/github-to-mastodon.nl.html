Van GitHub naar Mastodon

Vind je GitHub-vrienden op Mastodon

Veel ontwikkelaars vermelden hun Mastodon-account op GitHub. Mawkingbird kijkt bij de mensen die je op GitHub volgt en de eigenaren van repositories waaraan je een ster gaf. Je kunt ze vervolgens op Mastodon volgen.

  1. Log in met Mastodon

    Volgen doe je met je eigen Mastodon-account, dus dat komt eerst.

  2. Koppel GitHub

    Plak een persoonlijk toegangstoken van GitHub. De pagina laat zien hoe je er een maakt. GitHub laat browserapps niet op een andere manier inloggen. Het token blijft in deze browser.

  3. Zoek en volg

    Eerst worden profiellinks naar Mastodon bekeken, daarna volgt een beperkte zoekopdracht naar gebruikersnamen. Bij elke overeenkomst staan de aanwijzingen. Jij kiest wie je volgt.

Vragen

Waar gaat mijn GitHub-token naartoe?

Het wordt in deze browser bewaard en alleen verstuurd naar api.github.com, nooit naar Mawkingbird. Je kunt het op GitHub op elk moment intrekken.

Volgt dit automatisch mensen?

Nee. Bij elke overeenkomst met de aanwijzingen staat een knop die je zelf indrukt om te volgen.
