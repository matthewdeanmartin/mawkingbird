Fragen

Wie sieht ein Mastodon-Name aus?

Er hat zwei Teile: deinen Benutzernamen und deinen Server, etwa @matthew_martin@mastodon.social. Der Benutzername darf Buchstaben, Ziffern und Unterstriche enthalten, bis zu 30 Zeichen, und Großbuchstaben ergeben keinen anderen Namen.

Warum mehr als einen Server prüfen?

Jeder Server hat seine eigenen Benutzernamen. Ein auf mastodon.social vergebener Name kann woanders frei sein, und Leute auf jedem Server können dir so oder so folgen.

Ist „sieht frei aus“ eine Garantie?

Nicht ganz. Es heißt, dass auf diesem Server heute niemand den Namen hat. Namen gelöschter Konten bleiben reserviert, und Admins können Wörter reservieren, deshalb hat das Anmeldeformular das letzte Wort.

Welche Server zählen als die größten?

Die mit den meisten Anmeldungen im Verzeichnis von joinmastodon.org, das Server auflistet, die dem Server-Abkommen von Mastodon folgen. Manche lassen neue Konten erst von Admins freigeben; die Liste sagt, welche.
