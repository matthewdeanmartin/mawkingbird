Pertanyaan

Seperti apa handle Mastodon?

Dua bagian: nama pengguna dan server, misalnya @matthew_martin@mastodon.social. Nama pengguna bisa berisi huruf, angka, dan garis bawah, hingga 30 karakter. Huruf besar tidak membuat nama berbeda.

Mengapa memeriksa lebih dari satu server?

Setiap server memiliki nama pengguna sendiri. Nama yang sudah dipakai di mastodon.social mungkin tersedia di server lain. Orang dari server mana pun tetap bisa mengikutimu.

Apakah tampaknya tersedia berarti dijamin?

Tidak sepenuhnya. Artinya belum ada akun di server itu yang memakai nama tersebut hari ini. Nama akun yang dihapus tetap dicadangkan, dan admin bisa mencadangkan kata. Formulir pendaftaran yang menentukan akhirnya.

Server mana yang dianggap terbesar?

Server dengan pendaftaran terbanyak di direktori joinmastodon.org yang mengikuti kesepakatan server Mastodon. Sebagian perlu persetujuan admin untuk akun baru; daftar menunjukkan yang mana.
