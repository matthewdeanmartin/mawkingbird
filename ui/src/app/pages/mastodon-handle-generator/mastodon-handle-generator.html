Questions

What does a Mastodon handle look like?

Two parts: your username and your server, like @matthew_martin@mastodon.social. The username can use letters, numbers and underscores, up to 30 characters, and capital letters don't make a different name.

Why check more than one server?

Each server has its own usernames. A name taken on mastodon.social can be free on another server, and people on every server can follow you either way.

Is "looks free" a guarantee?

Not quite. It means nobody on that server has the name today. Names of deleted accounts stay reserved, and admins can reserve words, so the sign-up form has the final say.

Which servers count as the biggest?

The ones with the most sign-ups in the joinmastodon.org directory of servers that follow Mastodon's server covenant. Some need an admin to approve new accounts; the list says which.
