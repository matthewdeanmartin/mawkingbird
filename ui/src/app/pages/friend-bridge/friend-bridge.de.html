Fragen

Folgt es Leuten, ohne zu fragen?

Nein. Wer seinen anderen Namen selbst angegeben hat, ist für dich angehakt; Vermutungen aus einer Namenssuche nicht. Niemandem wird gefolgt, bevor du auf „Folgen“ drückst.

Warum fehlen manche Leute?

Zugeordnet werden nur Leute, die ihren {{ copy.to }}-Namen nennen oder die eine Namenssuche findet. Jemand mit einem häufigen Namen und ohne Namen in der Bio taucht vielleicht nicht auf.

Geht es auch andersherum?

Ja: @if (copy.source === 'bluesky') { deine Mastodon-Follows auf Bluesky finden. } @else { deine Bluesky-Follows auf Mastodon finden. }

Wo werden meine Anmeldungen gespeichert?

In diesem Browser. Mawkingbird spricht direkt mit deinem Mastodon-Server und mit Bluesky; es gibt keinen Mawkingbird-Server dazwischen, der deine Konten verwahrt.
