よくある質問

確認なしでフォローされますか？

いいえ。本人がもう一方のアカウントを書いている人にはチェックが入りますが、名前検索で見つかった候補には入りません。「フォロー」を押すまで誰もフォローされません。

見つからない人がいるのはなぜ？

見つかるのは、{{ copy.to }} のアカウントを書いている人か、名前検索で見つかる人だけです。よくある名前でプロフィールにアカウントを書いていない人は見つからないことがあります。

逆方向もできますか？

はい。 @if (copy.source === 'bluesky') { Mastodon でフォローしている人を Bluesky で探すこともできます。 } @else { Bluesky でフォローしている人を Mastodon で探すこともできます。 }

ログイン情報はどこに保存されますか？

このブラウザーの中です。Mawkingbird はあなたの Mastodon サーバーや Bluesky と直接やりとりし、アカウントを預かる Mawkingbird のサーバーはありません。
