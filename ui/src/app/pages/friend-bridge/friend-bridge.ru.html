Вопросы

Инструмент подписывается без спроса?

Нет. Люди, сами указавшие другой адрес, уже отмечены, а предположения из поиска по имени — нет. Никто не добавится до нажатия «Подписаться».

Почему некоторые люди не найдены?

Найти можно тех, кто указал адрес {{ copy.to }} или находится по имени. Человек с распространённым именем без адреса в биографии может не появиться.

Где хранятся данные входа?

В этом браузере. Mawkingbird общается напрямую с твоим сервером Mastodon и с Bluesky. Между ними нет сервера Mawkingbird, который хранит твои учётные записи.
