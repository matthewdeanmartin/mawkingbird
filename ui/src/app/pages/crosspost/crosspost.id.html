Pertanyaan

Apakah salinan di Bluesky sama persis?

Teksnya sama. Salinan Bluesky selalu publik. Jajak pendapat dan peringatan konten tetap ada hanya di salinan Mastodon karena Bluesky tidak memiliki padanannya.

Di mana data masukku disimpan?

Di browser ini. Mawkingbird berkomunikasi langsung dengan server Mastodon-mu dan Bluesky. Tidak ada server Mawkingbird di tengah yang menyimpan akunmu.
