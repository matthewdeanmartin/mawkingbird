Frågor

Hur ser ett Mastodon-användarnamn ut?

Två delar: ditt användarnamn och din server, till exempel @matthew_martin@mastodon.social. Namnet kan innehålla bokstäver, siffror och understreck, upp till 30 tecken. Stora bokstäver gör inte namnet annorlunda.

Varför kontrollera fler än en server?

Varje server har sina egna användarnamn. Ett namn som är upptaget på mastodon.social kan vara ledigt på en annan server. Andra kan följa dig från vilken server som helst.

Är verkar ledigt en garanti?

Inte riktigt. Det betyder att inget konto på servern använder namnet i dag. Namn från borttagna konton förblir reserverade och administratörer kan reservera ord. Registreringsformuläret avgör till sist.

Vilka servrar räknas som störst?

De med flest registreringar i joinmastodon.orgs katalog över servrar som följer Mastodons serveröverenskommelse. Några kräver att administratörer godkänner nya konton; det står i listan.
