Vragen

Hoe ziet een Mastodon-gebruikersnaam eruit?

Twee delen: je gebruikersnaam en je server, zoals @matthew_martin@mastodon.social. De gebruikersnaam mag letters, cijfers en underscores bevatten, tot 30 tekens. Hoofdletters maken geen andere naam.

Waarom meer dan één server controleren?

Elke server heeft eigen gebruikersnamen. Een naam die op mastodon.social bezet is, kan op een andere server vrij zijn. Mensen kunnen je vanaf elke server volgen.

Is lijkt vrij een garantie?

Niet helemaal. Het betekent dat vandaag geen account op die server de naam gebruikt. Namen van verwijderde accounts blijven gereserveerd en beheerders kunnen woorden reserveren. Het aanmeldformulier beslist dus uiteindelijk.

Welke servers gelden als de grootste?

De servers met de meeste aanmeldingen in de lijst van joinmastodon.org die het Mastodon-serverconvenant volgen. Sommige vereisen goedkeuring voor nieuwe accounts; dat staat erbij.
