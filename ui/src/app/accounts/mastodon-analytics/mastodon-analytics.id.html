Pertanyaan

Ke mana dataku dikirim?

Tidak ke tempat baru. Postingan dan pengikut dibaca dari server Mastodon-mu, lalu dihitung di browser ini. Mawkingbird tidak menyimpan salinan.

Mengapa jangkauan hanya perkiraan?

Mastodon tidak menghitung tayangan. Jangkauan diperkirakan dari pengikut dan interaksi mereka. Keterangan itu ditampilkan di samping angkanya.
