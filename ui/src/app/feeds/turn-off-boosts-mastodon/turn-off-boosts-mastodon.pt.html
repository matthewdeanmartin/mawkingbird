Perguntas

Isso deixa de seguir alguém?

Não. Você continua seguindo todo mundo, e as publicações e respostas das próprias pessoas continuam chegando no seu início. Só os boosts somem.

Dá para desfazer?

Dá. A mesma página liga os boosts de novo para todo mundo, e para uma conta só, é no perfil dela.

E quem eu seguir depois?

Contas novas começam com os boosts ligados, como sempre no Mastodon. Rode de novo quando quiser; só muda as contas que precisam.

Por que demora um pouco?

O Mastodon não tem um ajuste “para todo mundo de uma vez”, então cada conta que você segue é alterada separadamente. Uma lista longa leva alguns minutos.
