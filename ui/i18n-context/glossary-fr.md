# Glossaire de l'interface française

Registre : texte d'interface neutre et concis ; **tutoiement** systématique (tu/ton), jamais « vous ».
Conserver tels quels les noms de produits, le code, les URL, le HTML et tous les paramètres `{{ ... }}`.

| English | Français | Remarque |
|---|---|---|
| post | post / publication | publication sociale, pas un poteau |
| boost / reblog | partager / partage | rediffusion d'un post, pas une amplification |
| boosted | partagé | |
| favourite | ajouter aux favoris / favori | réaction |
| bookmark | signet / ajouter aux signets | ne pas confondre avec les favoris |
| follow / unfollow | suivre / ne plus suivre | pas de traque |
| feed | flux | flux de posts |
| timeline | fil | |
| thread | fil de discussion | discussion, pas du fil à coudre |
| handle | identifiant | pas une poignée |
| mute / block | masquer / bloquer | conserver la distinction |
| report | signaler | pas un rapport-document |
| content warning | avertissement de contenu | CW dans les libellés courts |
| server / instance | serveur / instance | termes Mastodon, pas un exemple |
| reply | répondre | |
| notifications | notifications | |
| fail whale | fail whale | blague, pas un incident maritime |
| API call | appel d'API | pas un appel téléphonique |
