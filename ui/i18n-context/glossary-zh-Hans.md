# Simplified Chinese (`zh-Hans`) terminology

Use widely understood written Mandarin in Simplified Chinese. Omit the reader
pronoun where natural and use 你 when needed. Use one dictionary across regions.

| English | Simplified Chinese |
| --- | --- |
| Home / Algo / Feeds / Write | 首页 / 算法 / 动态 / 写作 |
| Post / publish | 帖子 / 发布 |
| Boost / reply / quote | 转发 / 回复 / 引用 |
| Timeline / thread | 时间线 / 讨论串 |
| Follow / unfollow | 关注 / 取消关注 |
| Mute / block | 静音 / 屏蔽 |
| Account / profile / server | 账号 / 个人资料 / 服务器 |
| Settings / interface language | 设置 / 界面语言 |

Keep placeholders, links, handles, markup, and product names intact. Retain
both keys in existing plural pairs and use the same wording where appropriate.
