# Latvian (`lv`) terminology

Use contemporary Latvian and informal singular **tu**, **tavs** throughout. Short
controls use the infinitive (Saglabāt, Dzēst); explanatory instructions may use
the singular imperative (Izvēlies, Ievadi). Preserve Latvian diacritics, all
placeholder names, markup, product names and literal example URLs/handles.

Timeline is **laika līnija**; **laika josla** means time zone. Boost means social
re-sharing, not amplification. Thread is a conversation, not sewing. Mute does
not block the account. A thread notification switch explicitly describes turning
notifications on/off. API calls are **API izsaukumi**, not telephone calls. Keep
GitHub's scope and permission labels (`gist`, `Permissions → Repository`) literal
so users can find them in the external interface.

This first pass covers the shared 2,758-key work order, including login, search,
Lite and required offline explanations. Long articles remain in English fallback.
All selected keys passed merge validation, and identical-English entries were
reviewed for brands, identifiers and legitimate cognates. Native-speaker and
visual review remain necessary before production promotion.
