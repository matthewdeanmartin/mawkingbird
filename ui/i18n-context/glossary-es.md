# Glosario de interfaz en español

Registro: español internacional neutro, claro y conciso. Se usa `tú` en singular
y `ustedes` en plural; se evitan regionalismos innecesarios y el desdoblamiento
de género cuando una redacción neutral y natural es posible.

## Términos canónicos de la aplicación social

| Inglés | Español | Evitar / nota |
|---|---|---|
| post | publicación | `poste` (objeto físico) |
| boost / reblog | republicar | `impulsar`, que sugiere promoción |
| favourite | favorito | `preferido` cuando es la acción social |
| bookmark | marcador | distinto de favorito |
| follow / unfollow | seguir / dejar de seguir | no `perseguir` |
| follower / following | seguidor / siguiendo | `seguidos` solo cuando el sustantivo sea necesario |
| feed | feed / cronología | no alimento; `feed` para fuentes con nombre de producto |
| timeline | cronología | lista cronológica de publicaciones |
| thread | hilo | conversación, no hilo de coser |
| handle | nombre de usuario / identificador | nunca mango/manija |
| display name | nombre para mostrar | distinto del nombre de usuario |
| mute / unmute | silenciar / dejar de silenciar | distinto de bloquear |
| block / unblock | bloquear / desbloquear | distinto de silenciar |
| report | denunciar / denuncia | `informe` solo para documentos o resultados |
| direct message | mensaje directo | abreviado `MD` solo si el espacio lo exige |
| content warning | advertencia de contenido | `CW` puede conservarse en etiquetas compactas |
| server / instance | servidor / instancia | según el sustantivo inglés |
| local / federated | local / federado | vocabulario de Mastodon |
| moderation | moderación | |
| account | cuenta | `cuenta actual` es la activa, no una cuenta bancaria |
| API call | solicitud / llamada de API | nunca llamada telefónica |
| paste (item) | paste | nombre del objeto de pastebin; como verbo, `pegar` |
| light / dark theme | tema claro / oscuro | no luz/peso |
| fail whale | ballena de error | broma de página de error; no explicar de más |

Se conservan nombres de productos y redes (Mastodon, Bluesky, X, Twitter,
Mockingbird), código, URLs, consultas de búsqueda y marcadores de posición. Los
parámetros `{{ ... }}` y las etiquetas deben quedar idénticos al original.
