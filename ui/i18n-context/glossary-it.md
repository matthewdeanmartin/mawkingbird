# Glossario dell’interfaccia in italiano

Registro: italiano neutro, chiaro e conciso; seconda persona singolare informale
`tu`, plurale `voi`. Conserva nomi dei prodotti, codice, URL, HTML e tutti i
parametri `{{ ... }}` esattamente.

| Inglese | Italiano | Evitare / nota |
|---|---|---|
| post | post / pubblicazione | non palo |
| boost / reblog | ricondividere | non potenziare/promuovere |
| favourite | preferito | azione social |
| bookmark | segnalibro | distinto da preferito |
| follow / unfollow | seguire / smettere di seguire | non inseguire |
| feed / timeline | feed / timeline | flusso di post, non cibo |
| thread | discussione / thread | non filo da cucito |
| handle | nome utente / identificativo | non maniglia |
| mute / block | silenziare / bloccare | mantenerli distinti |
| report | segnalare / segnalazione | rapporto solo come documento |
| content warning | avviso sul contenuto | CW per etichette compatte |
| server / instance | server / istanza | termini di Mastodon |
| current account | account corrente | non conto bancario |
| API call | chiamata / richiesta API | non telefonata |
| paste (item) | paste | come verbo, incollare |
| light / dark theme | tema chiaro / scuro | non peso o illuminazione |
| fail whale | balena d’errore | battuta della pagina d’errore |
