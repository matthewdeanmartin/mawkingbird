# Malay (`ms`) terminology

Use Malaysian Malay, with **anda** where a pronoun helps. Omit it in short
controls and wherever the subject is clear.

| English | Malay |
| --- | --- |
| Post (noun) | hantaran |
| Post (verb) | siarkan |
| Boost / repost | kongsi semula (verb), perkongsian semula (noun) |
| Thread | bebenang |
| Feed / timeline | suapan / garis masa |
| Follow / following / followers | ikuti / diikuti / pengikut |
| Mute / block | senyapkan / sekat |
| Bookmark | penanda buku |
| Server / instance | pelayan |
| Interface language / posting language | bahasa antara muka / bahasa hantaran |
| Settings | tetapan |
| Outbox / offline | peti keluar / luar talian |

Keep product names, account handles and placeholder names as written. Malay
usually uses the same wording for both plural keys when a number is shown.
