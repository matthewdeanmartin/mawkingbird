# Arabic interface glossary

Use concise Modern Standard Arabic. Prefer action nouns for compact labels (حفظ، حذف، نشر) and direct imperatives in instructions (اختر، تحقّق، الصق). Use the same singular register across surfaces. Keep service and product names, handles, HTML tags, URLs, code samples, and interpolation tokens intact.

| English term                      | Arabic                                   | Usage                                                                                     |
| --------------------------------- | ---------------------------------------- | ----------------------------------------------------------------------------------------- |
| post / publish                    | منشور / نشر                              | An item versus the action.                                                                |
| reply                             | ردّ / إضافة رد / إرسال الرد              | A reply, opening the composer, and sending the composed reply.                            |
| boost / repost                    | إعادة نشر                                | In Twitter-specific controls, use إعادة تغريد for retweet.                                |
| quote                             | اقتباس                                   | Use نشر اقتباس for the final submit action.                                               |
| thread                            | سلسلة                                    | Use سلسلة منشورات when the noun needs clarification. Use محادثة for conversation.         |
| feed / timeline                   | خلاصة / خط زمني                          | A feed is a content source. Timeline is the chronological view or network timeline.       |
| handle / username                 | معرّف الحساب / اسم المستخدم              | A handle may include a server or a domain.                                                |
| hashtag / mention                 | وسم / إشارة                              | Preserve the literal # or @ in examples and tokenized labels.                             |
| paste                             | لصق / نص منشور                           | Clipboard actions use لصق. The publishing feature creates a نص منشور via خدمة نشر النصوص. |
| favourite / like / bookmark       | إضافة إلى المفضلة / إعجاب / علامة مرجعية | Mastodon favourites and network likes are separate from saved bookmarks.                  |
| mute / block / filter             | كتم / حظر / عامل تصفية                   | Keep the three actions distinct. Use تصفية for filtering as an action.                    |
| content warning / sensitive media | تحذير بشأن المحتوى / وسائط حساسة         | Keep content warnings distinct from the sensitive-media flag.                             |
| server / instance                 | خادم                                     | Use one term in user-facing Mastodon flows.                                               |
| Fediverse / Fedi                  | الشبكة الفيدرالية                        | Refers to the federated network of services.                                              |
| authorization token / AI token    | رمز وصول / وحدة نصية                     | Use مفتاح API for an API key.                                                             |
| API call / proxy                  | طلب API / وكيل                           | An API call is a network request.                                                         |
| outbox / draft                    | صندوق الصادر / مسودة                     | Preserve when posts send automatically, which account sends, and the half-hour safeguard. |
| bookmark / Spotlight endorsement  | علامة مرجعية / توصية                     | The Spotlight panel recommends resources and sites.                                       |
| passphrase / vault                | عبارة المرور / خزنة                      | Use كلمة المرور for an account password.                                                  |

For English singular and plural pairs that share a numeric placeholder, prefer a count label such as المنشورات: followed by the count. This reads naturally with Arabic plural categories and preserves the existing key and placeholder structure. When a template supplies the number separately, check the assembled sentence.

Review links, handles, URLs, times, shortcut keys, and direction arrows in the rendered right-to-left layout. Short left-to-right values inserted into otherwise Arabic sentences may require isolation in markup. Some sentences are assembled from adjacent keys, so review them and the English fallback together. Native-speaker review of narrow and wide layouts remains pending.

For moderation examples, تدليك إيروتيكي refers to erotic massage. خدمات جنسية alone can appear in general discussion. An explicit advertising phrase such as أقدم خدمات جنسية or خدمات جنسية مدفوعة is more specific. تدليك رياضي بعد الجري is ordinary sports massage.
