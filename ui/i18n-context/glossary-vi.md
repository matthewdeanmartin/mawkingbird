# Bảng thuật ngữ giao diện tiếng Việt

Văn phong: tiếng Việt trung tính, tự nhiên và ngắn gọn cho giao diện; tránh lạm dụng lối xưng hô trang trọng.
Giữ nguyên tên sản phẩm, mã, URL, HTML và mọi tham số `{{ ... }}`.

| English | Tiếng Việt | Ghi chú |
|---|---|---|
| post | bài đăng | bài đăng mạng xã hội |
| boost / reblog | đẩy bài / đăng lại | chia sẻ lại, không phải khuếch đại tín hiệu |
| favourite | yêu thích | phản ứng xã hội |
| bookmark | dấu trang | khác với yêu thích |
| follow / unfollow | theo dõi / bỏ theo dõi | không phải theo đuổi |
| feed / timeline | bảng tin / dòng thời gian | luồng bài đăng, không phải thức ăn |
| thread | chuỗi thảo luận | không phải chỉ may |
| handle | tên người dùng / định danh | không phải tay cầm |
| mute / block | ẩn / chặn | giữ rõ hai hành động |
| report | báo cáo vi phạm | không phải tài liệu báo cáo |
| content warning | cảnh báo nội dung | có thể dùng CW trong nhãn ngắn |
| server / instance | máy chủ / phiên bản | thuật ngữ Mastodon |
| current account | tài khoản hiện tại | không phải tài khoản ngân hàng |
| API call | lời gọi / yêu cầu API | không phải cuộc gọi điện thoại |
