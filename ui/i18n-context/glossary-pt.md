# Glossário da interface em português

Registro: português internacional neutro, claro e conciso, com tratamento por
`você` e plural `vocês`. Preserve nomes de produtos, código, URLs, HTML e todos
os parâmetros `{{ ... }}` exatamente.

| Inglês | Português | Evitar / nota |
|---|---|---|
| post | publicação | não poste físico |
| boost / reblog | republicar | não impulsionar/promover |
| favourite | favorito | ação social |
| bookmark | marcador | distinto de favorito |
| follow / unfollow | seguir / deixar de seguir | não perseguir |
| feed / timeline | feed / linha do tempo | fluxo de publicações, não alimento |
| thread | fio | conversa; `thread` é aceitável quando compacto |
| handle | nome de usuário / identificador | não alça |
| mute / block | silenciar / bloquear | manter distintos |
| report | denunciar / denúncia | relatório só para documento |
| content warning | aviso de conteúdo | CW em rótulos compactos |
| server / instance | servidor / instância | termos do Mastodon |
| current account | conta atual | não conta corrente bancária |
| API call | chamada / solicitação de API | não chamada telefônica |
| paste (item) | paste | como verbo, colar |
| light / dark theme | tema claro / escuro | não peso ou iluminação |
| fail whale | baleia de erro | piada da página de erro |
