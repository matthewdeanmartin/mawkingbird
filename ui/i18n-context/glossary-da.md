# Danish (`da`) terminology

Use contemporary Danish with informal **du**, never formal De/Dem. Omit pronouns
in short controls. Use Danish sentence case and æ, ø and å; preserve placeholders,
markup, product names, API identifiers and literal URL examples.

| English                        | Danish                                       |
| ------------------------------ | -------------------------------------------- |
| Post (noun / verb)             | opslag / udgiv                               |
| Blog post                      | blogindlæg                                   |
| Boost / repost                 | del / deling; genudgiv when publishing again |
| Share elsewhere                | del andre steder                             |
| Thread                         | tråd                                         |
| Feed / timeline                | feed / tidslinje                             |
| Follow / following / followers | følg / følger / følgere                      |
| Mute / unmute                  | skjul / vis igen                             |
| Block / unblock                | bloker / fjern blokering                     |
| Favourite                      | markér som favorit (verb), favorit (noun)    |
| Like                           | like (noun), lik (verb)                      |
| Bookmark                       | bogmærke (noun), bogmærk (verb)              |
| Server / instance              | server                                       |
| Handle                         | brugernavn                                   |
| Avatar / header                | profilbillede / topbillede                   |
| Draft / outbox                 | kladde / udbakke                             |
| Settings                       | indstillinger                                |
| Interface / posting language   | grænsefladesprog / opslagssprog              |
| Calm / Good stuff              | Ro / Godt indhold                            |
| Notification                   | notifikation                                 |
| Vault / passphrase             | boks / adgangssætning                        |

Mute hides a person's content without blocking them. Thread muting disables
notifications; those controls explicitly say “Slå notifikationer … fra”. Boost is
social re-sharing, never amplification. Feed is not animal food, and an API call
is an API-kald, never a telephone call. Preserve GitHub scope/permission labels
such as `gist` and `Permissions → Repository`, which users must locate verbatim.

This first pass contains the shared 2,758-key short-UI work order, including Lite,
offline copy, login and search. Long articles remain in English fallback. Mechanical merge
validation and an identical-English review were completed; visual/native-speaker
review is still needed before promotion from test/canary.
