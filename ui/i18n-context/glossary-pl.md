# Glosariusz polskiego interfejsu

Rejestr: neutralny, zwięzły polski interfejsowy; bez formalnego `Państwo`.
Zachowuj nazwy produktów, kod, adresy URL, HTML i wszystkie parametry `{{ ... }}`
bez zmian.

| Angielski | Polski | Unikać / uwaga |
|---|---|---|
| post | wpis / post | nie słup |
| boost / reblog | podbić / udostępnić ponownie | nie wzmacniać sygnału/promować |
| favourite | ulubione | akcja społecznościowa |
| bookmark | zakładka | odrębna od ulubionych |
| follow / unfollow | obserwować / przestać obserwować | nie śledzić jak prześladowca |
| feed / timeline | kanał / oś czasu | strumień wpisów, nie żywność |
| thread | wątek | rozmowa, nie nić do szycia |
| handle | nazwa użytkownika / identyfikator | nie uchwyt |
| mute / block | wyciszyć / zablokować | zachować rozróżnienie |
| report | zgłosić / zgłoszenie | raport tylko jako dokument |
| content warning | ostrzeżenie o treści | CW w krótkich etykietach |
| server / instance | serwer / instancja | terminy Mastodona |
| current account | bieżące konto | nie rachunek bieżący bankowy |
| API call | wywołanie / żądanie API | nie rozmowa telefoniczna |
| paste (item) | paste | jako czasownik: wkleić |
| light / dark theme | jasny / ciemny motyw | nie ciężar/światło |
| fail whale | wieloryb błędu | żart na stronie błędu |
