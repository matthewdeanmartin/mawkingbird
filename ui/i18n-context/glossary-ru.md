# Глоссарий русского интерфейса

Регистр: нейтральный, лаконичный текст интерфейса; `ты` для одного пользователя, `вы` для нескольких.
Сохранять названия продуктов, код, URL, HTML и все параметры `{{ ... }}` без изменений.

| English | Русский | Примечание |
|---|---|---|
| post | пост / публикация | социальная публикация |
| boost / reblog | продвинуть / репост | повторная публикация, не усиление сигнала |
| favourite | избранное | реакция |
| bookmark | закладка | не смешивать с избранным |
| follow / unfollow | подписаться / отписаться | не преследовать |
| feed / timeline | лента | поток постов |
| thread | ветка / цепочка | дискуссия, не швейная нить |
| handle | имя пользователя / адрес | не физическая ручка |
| mute / block | игнорировать / заблокировать | сохранять различие |
| report | пожаловаться / жалоба | не отчёт-документ |
| content warning | предупреждение о содержании | CW в кратких метках |
| server / instance | сервер / экземпляр | термины Mastodon |
| current account | текущая учётная запись | не банковский счёт |
| API call | вызов / запрос API | не телефонный звонок |
