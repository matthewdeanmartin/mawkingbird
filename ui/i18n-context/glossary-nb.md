# Norwegian Bokmål (`nb`) terminology

Use contemporary Bokmål and address the reader as **du**. Use short imperatives
in buttons and sentence case in labels. Use Norwegian quotation marks («…»)
and preserve interpolation names, inline markup, URLs, and literal examples.

Use **lim inn** for a clipboard action and **tekstklipp** for a published paste.
Boosting shares an existing post. Use **publiser på nytt** when publishing a
new version of a post. Muting a thread controls its notifications. An API call
is a **forespørsel**. Preserve external setup labels such as GitHub's
`Permissions → Repository` and Google's `Authorized redirect URIs`, which the
reader needs to find on those sites.

The moderation phrases **erotisk massasje** and **eskorttjenester** are
idiomatic and specific. **Sportsmassasje etter løpeturen** is ordinary text.
