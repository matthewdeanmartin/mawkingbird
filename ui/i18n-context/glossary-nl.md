# Woordenlijst voor de Nederlandse interface

Register: helder, beknopt Standaardnederlands; informeel enkelvoud `je`, meervoud
`jullie`. Behoud productnamen, code, URL’s, HTML en alle parameters `{{ ... }}`
exact.

| Engels | Nederlands | Vermijd / opmerking |
|---|---|---|
| post | bericht | geen paal/post als fysiek object |
| boost / reblog | boosten / opnieuw delen | geen versterken/promoten |
| favourite | favoriet | sociale actie |
| bookmark | bladwijzer | anders dan favoriet |
| follow / unfollow | volgen / ontvolgen | geen achtervolgen |
| feed / timeline | feed / tijdlijn | berichtenstroom, geen voedsel |
| thread | gesprek / thread | geen naaigaren |
| handle | gebruikersnaam / accountnaam | geen handvat |
| mute / block | dempen / blokkeren | houd ze verschillend |
| report | rapporteren / melding | verslag alleen als document |
| content warning | inhoudswaarschuwing | CW in compacte labels |
| server / instance | server / instantie | Mastodon-termen |
| current account | huidig account | geen betaalrekening |
| API call | API-aanroep / verzoek | geen telefoongesprek |
| paste (item) | paste | als werkwoord: plakken |
| light / dark theme | licht / donker thema | geen gewicht |
| fail whale | foutwalvis | grap op de foutpagina |
