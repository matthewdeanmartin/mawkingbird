# Ordlista för det svenska gränssnittet

Register: neutral, kortfattad standardsvenska för ett socialt medieprogram.
Använd informellt `du` i singular och `ni` i plural. Bevara produktnamn, kod,
webbadresser, HTML och alla parametrar `{{ ... }}` exakt.

| Engelska | Svenska | Undvik / kommentar |
|---|---|---|
| post | inlägg | inte postförsändelse |
| boost / reblog | boosta / dela vidare | inte signal- eller marknadsföringsförstärkning |
| favourite | favoritmarkera / favorit | social åtgärd |
| bookmark | bokmärke | skiljs från favorit |
| follow / unfollow | följ / sluta följa | inte förfölja |
| feed / timeline | flöde / tidslinje | ström av inlägg, inte mat |
| thread | tråd | konversation, inte sytråd |
| handle | användarnamn / konto-id | inte handtag |
| mute / block | tysta / blockera | håll isär |
| report | anmäl / anmälan | rapport endast för dokument |
| content warning | innehållsvarning | CW i kompakta etiketter |
| server / instance | server / instans | Mastodon-termer |
| current account | aktuellt konto | inte bankkonto |
| API call | API-anrop | inte telefonsamtal |
| paste (item) | paste | som verb: klistra in |
| light / dark theme | ljust / mörkt tema | gränssnittstema |
| fail whale | felval | skämt på felsidan |
