# Romanian (`ro`) terminology

Use contemporary Romanian with diacritics (ș/ț with comma below), informal singular
**tu**, and direct singular imperatives. Omit pronouns in controls where possible.
Keep product names, account handles, URLs, code and interpolation names unchanged.

Distinguish a reply action (Răspunde) from a reply type label (Răspuns), and
publishing a text fragment (Publică fragmentul) from pasting clipboard text
(Lipește). Boost always means re-sharing a social post, never signal amplification.
The fail-whale joke is adapted as **Balena erorilor**. **Date personale** is the
compact footer label for privacy, constrained to 16 characters; the settings page
uses **Confidențialitate**. Preserve the **Calm**, **Lite**, **Plus** and **Algo**
feature names. A thread/storm is a sequence of posts (serie), not a weather event.

This first pass contains 2,758 short and practical interface strings, including
all required Lite/offline copy. Missing strings retain the English fallback.
Long editorial prose is deferred. The locale remains in progress pending native
speaker review and complete narrow/wide visual review; mechanical checks alone
do not certify linguistic or layout quality.
