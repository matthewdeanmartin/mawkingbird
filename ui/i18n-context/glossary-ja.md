# Japanese glossary

## Register

Use polite but ordinary Japanese throughout the interface: です／ます form. Do not use
keigo or plain/casual endings. Japanese has no grammatical plural; do not add plural suffixes.
Avoid gendered wording around interpolated names. Japanese normally has no spaces, so keep
URLs, handles, hashtags, code, and product names exactly as supplied.

## Locked terminology

| English | Japanese | Sense / trap to avoid |
|---|---|---|
| Boost | ブースト | Re-share a post, not amplify/increase a signal |
| Post | 投稿 | Status message, not mail or a physical post |
| Toot | トゥート | Mastodon’s whimsical post word; not a horn sound |
| Handle | ハンドル | Fediverse address such as `@user@server.social`, not a grip/door handle |
| Instance / Server | インスタンス／サーバー | A fediverse server, not an example or occurrence |
| Feed | フィード | Stream of posts, not food or feeding |
| Timeline | タイムライン | Scrollable stream, not a chronology graphic |
| Thread | スレッド | Chain of replies, not sewing or screw thread |
| Follow / Unfollow | フォロー／フォロー解除 | Subscribe to an account, not pursue or stalk |
| Mute | ミュート | Hide posts without unfollowing; distinct from Block |
| Block | ブロック | Sever contact entirely; distinct from Mute |
| Filter | フィルター | Rule hiding matching posts, not a coffee/photo filter |
| Like / Favourite | いいね／お気に入り | Mark a post positively |
| Light / Dark | ライト／ダーク | Colour themes, not illumination or weight |
| Paste | Paste | Pastebin product noun; do not translate as glue/pasta |
| Call (API) | APIリクエスト | Server request, not a telephone call |
| Current account | 現在のアカウント | Account in use, not a bank account |
| Fediverse | Fediverse | Federated social network; keep the coinage |
| Fail whale | 失敗クジラ | Error-page mascot joke; do not describe a literal failed whale |
| Starter kit | スターターキット | Curated accounts to follow, not a beginner’s toolbox |
| Interface language | インターフェース言語 | App UI language, distinct from posting/known languages |
