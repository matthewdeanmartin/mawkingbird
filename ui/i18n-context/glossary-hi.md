# हिन्दी UI शब्दावली

शैली: सहज, संक्षिप्त और आधुनिक UI हिन्दी; उपयोगकर्ता के लिए `आप` का संगत प्रयोग।
उत्पाद नाम, कोड, URL, HTML और सभी `{{ ... }}` पैरामीटर जैसे हैं वैसे रखें।

| English | हिन्दी | नोट |
|---|---|---|
| post | पोस्ट | सोशल मीडिया पोस्ट |
| boost / reblog | बूस्ट / दोबारा साझा करें | सिग्नल बढ़ाना नहीं |
| favourite | पसंदीदा | सोशल प्रतिक्रिया |
| bookmark | बुकमार्क | पसंदीदा से अलग |
| follow / unfollow | फ़ॉलो / अनफ़ॉलो | पीछा करना नहीं |
| feed / timeline | फ़ीड / टाइमलाइन | पोस्ट का प्रवाह, भोजन नहीं |
| thread | थ्रेड / चर्चा शृंखला | सिलाई का धागा नहीं |
| handle | यूज़रनेम / अकाउंट पहचान | भौतिक हैंडल नहीं |
| mute / block | म्यूट / ब्लॉक | दोनों को अलग रखें |
| report | रिपोर्ट करें / शिकायत | दस्तावेज़ रिपोर्ट नहीं |
| content warning | सामग्री चेतावनी | छोटे लेबल में CW |
| server / instance | सर्वर / इंस्टेंस | Mastodon शब्द |
| current account | मौजूदा अकाउंट | बैंक खाता नहीं |
| API call | API कॉल / अनुरोध | फ़ोन कॉल नहीं |
