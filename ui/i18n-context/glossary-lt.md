# Lithuanian (`lt`) terminology

Use contemporary Lithuanian with informal singular address (`tu`, `tavo`). Use
infinitives for action labels and singular imperatives in guidance. Do not mix in
formal plural address. Keep Lithuanian diacritics and quotation marks (`„…“`).

| English                      | Lithuanian                       |
| ---------------------------- | -------------------------------- |
| Post (noun / verb)           | įrašas / skelbti                 |
| Boost / repost               | pasidalyti / pasidalijimas       |
| Quote                        | cituoti / citata                 |
| Thread                       | gija                             |
| Feed / timeline              | srautas / laiko juosta           |
| Follow / followers           | sekti / sekėjai                  |
| Mute / unmute                | nutildyti / panaikinti nutildymą |
| Block / unblock              | blokuoti / atblokuoti            |
| Favourite                    | pažymėti mėgstamu                |
| Like                         | patiktukas                       |
| Bookmark                     | žymelė                           |
| Server / instance            | serveris                         |
| Handle                       | paskyros adresas                 |
| Settings / preferences       | nuostatos                        |
| Interface / posting language | sąsajos kalba / skelbimo kalba   |
| Draft / outbox               | juodraštis / siunčiamieji        |
| Offline                      | be ryšio                         |
| Data saver                   | duomenų taupymas                 |
| Cache                        | podėlis                          |
| Calm / Algo                  | Ramybė / Algoritmas              |

Preserve product names, account addresses, URLs, source examples, technical
identifiers, placeholders and emoji. `Paste` identifies a pastebin item or service
and stays `Paste`; the clipboard action is `įklijuoti` (the friends-import sentence
uses `Įklijuok`). A boost re-shares a post rather than amplifying a signal. Network
and API requests are `užklausos`, not telephone calls. Theme `Light` is `Šviesi`.
Token as an access credential is `prieigos raktas`; model context uses `žetonai`.

The first pass contains exactly 2,758 priority strings, including the longer
required Lite/offline safeguards. It uses the existing one/other source key set;
additional Lithuanian plural forms require a separate shared-code decision.
English remains the fallback for the rest. Merge validation checks placeholders,
markup and declared length budgets; native-speaker review and narrow/wide visual
review remain before production promotion.
