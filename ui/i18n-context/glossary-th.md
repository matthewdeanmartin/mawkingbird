# Thai (`th`) glossary

Use neutral, conversational Thai. Omit the pronoun where the action or subject
is clear. Use คุณ when addressing the reader and ฉัน for first-person choices.
Omit gendered courtesy particles. Use plain, direct language for permissions,
deletion, automatic posting and other consequential actions.

Use the same phrase for an action referenced in instructions and on its
button. Keep the original handles, placeholders, exact URLs, code, protocol
names and product names such as Mawkingbird, Mastodon, Bluesky and OpenRouter.
Use classifiers such as คน for people, บัญชี for accounts and ครั้ง for events.
Thai uses the same wording across plural keys where the count is shown.

Check Thai native wording and layout before production promotion, especially
narrow buttons, sentences split across links, access and moderation labels, and
the automatic-send and half-hour review rules in the offline outbox. Review line
height with Thai vowels and tone marks. English fallback remains for keys
outside the initial work order.
