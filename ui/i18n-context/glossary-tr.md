# Türkçe arayüz sözlüğü

Kayıt: tarafsız ve kısa arayüz Türkçesi; tekil kullanıcı için `sen`, çoğul için `siz`.
Ürün adlarını, kodu, URL'leri, HTML'yi ve tüm `{{ ... }}` parametrelerini değiştirmeden koru.

| English | Türkçe | Not |
|---|---|---|
| post | gönderi | sosyal medya gönderisi |
| boost / reblog | öne çıkar / yeniden paylaş | sinyal güçlendirme değil |
| favourite | favori | sosyal tepki |
| bookmark | yer imi | favoriden ayrı |
| follow / unfollow | takip et / takibi bırak | peşine düşmek değil |
| feed / timeline | akış / zaman akışı | gönderi akışı, yiyecek değil |
| thread | ileti dizisi | dikiş ipliği değil |
| handle | kullanıcı adı / hesap kimliği | kapı kolu değil |
| mute / block | sessize al / engelle | ayrı eylemler |
| report | bildir / bildirim | belge anlamındaki rapor değil |
| content warning | içerik uyarısı | kısa etiketlerde CW |
| server / instance | sunucu / örnek | Mastodon terimleri |
| current account | geçerli hesap | cari banka hesabı değil |
| API call | API çağrısı / isteği | telefon görüşmesi değil |
