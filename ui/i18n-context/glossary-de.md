# Glossar der deutschen Oberfläche

Register: neutraler, knapper Oberflächentext; durchgehend **du/dein**, niemals „Sie".
Produktnamen, Code, URLs, HTML und alle `{{ ... }}`-Parameter unverändert lassen.

| English | Deutsch | Anmerkung |
|---|---|---|
| post | Post / Beitrag | soziale Veröffentlichung, kein Zaunpfahl |
| boost / reblog | boosten / Boost | Weiterverbreiten fremder Posts, keine Signalverstärkung |
| boosted | geboostet | |
| favourite | favorisieren / Favorit | Reaktion |
| bookmark | Lesezeichen | nicht mit Favoriten vermischen |
| follow / unfollow | folgen / nicht mehr folgen | kein Verfolgen |
| feed | Feed | Beitragsstrom, keine Fütterung |
| timeline | Timeline | |
| thread | Thread | Diskussion, kein Nähfaden |
| handle | Handle | Adresse, kein Griff |
| mute / block | stummschalten / sperren | Unterschied bewahren |
| report | melden | keine Berichtsdatei |
| content warning | Inhaltswarnung | CW in Kurzlabels |
| server / instance | Server / Instanz | Mastodon-Begriffe, kein Beispiel |
| reply | antworten | |
| notifications | Benachrichtigungen | |
| fail whale | Fail Whale | Scherz, kein Meeresvorfall |
| API call | API-Aufruf | kein Telefonanruf |
