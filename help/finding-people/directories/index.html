Finding people

Find people through directories#

A directory is a browsable list of accounts that chose or were selected to appear there. Use one when you want to explore rather than search for a known name.

Browse the server directory#

  1. Open More → Find Friends.
  2. Choose Profile directory.
  3. Choose Recently active or Recently joined.
  4. Open interesting profiles and follow selectively.

Turn on This server only to limit the directory to accounts hosted on the current server. Turn it off to include remote accounts that the server has encountered.

The server directory is not a complete membership list. Only opted-in accounts appear, and the remote portion depends on what that server has seen.

Use an offsite directory#

Choose Offsite directories on Find Friends to see discovery tools maintained by other people. These open in another site.

When you find someone:

  1. Copy their full handle or profile address.
  2. Return to Mawkingbird.
  3. Paste it into Search with Accounts selected.
  4. Check the profile and follow from Mawkingbird.

You can collect several handles and import them as a follow list.

Treat directory entries as suggestions#

Directories have different inclusion and review policies. Appearance in a directory is not proof of identity, activity, or trustworthiness. Check the handle, biography, links, and recent posts before following.
