Posting

Write a thread#

A thread is a sequence of connected posts from you. Use one when a message does not fit comfortably into a single post or when distinct points deserve separate parts.

Create a thread#

  1. Start a new post.
  2. Write the first part.
  3. Choose the Add another post button marked with a thread symbol.
  4. Write the next part in the new box.
  5. Add more boxes as needed.
  6. Review every part.
  7. Choose Post all.

Each box has its own length limit. Mawkingbird warns you if any part is too long.

Use the remove button beside a thread box to take that part out before publishing.

How the parts are connected#

Mawkingbird publishes the first post, then publishes each later part as a reply to the one before it. Bluesky threads work the same way: each box becomes the next reply in the chain.

Media, a poll, or a content warning belongs to the first Fedi post in the thread. The later parts inherit the visibility and continue as replies.

Limits#

Threads cannot be scheduled. Remove the extra thread boxes before choosing a future publishing time.

A thread cannot be sent to a blog or paste service from this composer.

When publishing to Both, each part must fit Bluesky's shorter limit because the same text is going to both destinations.
