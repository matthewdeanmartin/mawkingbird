# Inbox views (November 2026)

Build: the commit "inbox work" (2026-11-26). Spec:
[spec/sprint/inbox-views-2026-11.md](../sprint/inbox-views-2026-11.md).

## You need

- A Mastodon account with recent likes, boosts, a few mentions and new followers.
- A Bluesky connection, for one pass on Both.

## Steps

- [ ] Inbox opens on **Conversations**: only mentions, replies, quotes and things to act on.
- [ ] The strip reads Conversations | Stats | Who | Stream, each with a quiet "+N" when something is new.
- [ ] **Stats:** one line per post, always open, with the likers' and boosters' faces; clicking a face opens the profile.
- [ ] **Who:** follow requests first, then new followers with faces, then Accounts new to you (Mastodon).
- [ ] **Stream:** everything, newest first, likes on one post grouped as one row.
- [ ] The from-filter (e.g. Mutuals) and the network switch apply in every view; the type picker lists only that view's kinds.
- [ ] Open a post from Stats, press Back: still on Stats.
- [ ] Inbox dot: a new like does not light it; a mention or a new follower does.
- [ ] Wellness "limited notifications": no Stats tab.
