Posting

Save and return to a draft#

A draft holds writing that has not been published. Saving a draft gives you time to stop, review, and return later.

Save from the composer#

  1. Start writing a post.
  2. Open the Drafts choice beneath the writing box. In a compact composer, choose the notebook button first.
  3. Choose Save as draft.

Mawkingbird also keeps half-written text automatically. The explicit save makes your intention clear and puts the draft in the Drafts list.

Continue a draft#

  1. Open More → Drafts.
  2. Find the draft.
  3. Choose Continue.
  4. Review the destination, visibility, text, and any additions.
  5. Publish it when ready.

Removing a draft deletes the saved copy. It does not delete a post, because the draft was never published.

Local drafts stay in this browser#

A draft labelled local is stored in the current browser. It is private and quick to save, but it does not automatically follow you to another device.

Clearing the browser's saved site data, using a private window, or changing browsers may make local drafts unavailable. Do not use a local draft as the only copy of irreplaceable writing.

Thoughtful posting#

When Thoughtful posting is enabled in Settings → Writing, the main Write path saves first instead of publishing immediately. Open Drafts later and choose the deliberate publishing step.

The Drafts page can also show other kinds of unfinished or scheduled writing. Read the label on each item: local, parked, self, and paste do not have the same privacy or storage behavior.
